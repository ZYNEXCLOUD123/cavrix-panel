## Notice

CAVRIX Panel is an independently developed product that builds upon concepts and architectural patterns from JTG Panel. While the original JTG Panel code served as inspiration, CAVRIX Panel has been substantially rewritten and improved with:

- PostgreSQL database (instead of JSON file storage)
- Separate frontend/backend architecture
- Enhanced security features
- Role-based access control (RBAC)
- Improved Docker integration
- Modern UI/UX design system
- Comprehensive API with OpenAPI documentation
- Audit logging system
- Node management system
- And many other improvements

All original attribution and credit to the JTG Panel project and its creator Jishnu are preserved as required by the MIT license.
